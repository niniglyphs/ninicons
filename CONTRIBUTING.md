# Contributing

Thank you for wanting to help.

Every Ninicon is drawn by hand in a separate studio, checked against the style guide and reviewed before it ships.
This repository receives each release from there, so the SVG files and packages here are build output: a pull
request that edits them can't be merged, because the next release would overwrite it.

What helps most:

- **Request an icon** with the [request form](https://github.com/niniglyphs/ninicons/issues/new?template=request-an-icon.yml).
  Say what it's for and where you'd use it; a link to a reference helps.
- **Report a problem** with an icon or a package with the [bug form](https://github.com/niniglyphs/ninicons/issues/new?template=bug.yml):
  a drawing that looks wrong at some size or style, a package that misbehaves in your framework, a missing search tag.
- **Fix an example**: the apps in `examples/` come from the studio too, so a pull request there is read and
  carried into the next release rather than merged here as it is. Say what was wrong and the fix is taken over.

Please be kind in issues and reviews.
